## 상위 5개

1. **첫 QPushButton 이 저절로 기본 단추가 되어 빨갛게 칠해진다(상).** `theme.py:231` 이 `QPushButton:default` 를 강조색으로 칠하고, Qt 는 대화상자의 첫 단추를 autoDefault 로 잡는다. 그래서 분할의 「찾아보기」, 서명의 「삭제」, 스탬프 만들기의 「찾아보기」, 스탬프 관리의 「추가」, 머리글의 「페이지 번호 추가」가 빨갛고 정작 「확인」은 회색이다. Enter 도 그 단추로 간다. 서명의 「삭제」는 사용 안 함 상태라 빨강 위 흐린 글자로 읽히지 않는다.
2. **포커스 테두리가 강조색(빨강)이라 오류처럼 보인다(중).** 인쇄의 프린터 칸, 전자 서명의 「로그인」 칸, 비밀번호 칸이 창을 열자마자 빨간 테두리로 뜬다.
3. **저장 경로에 `/` 와 `₩` 가 섞인다(중).** 병합·압축·일괄의 경로 칸이 `C:/Users/…/Desktop₩PDFmetry₩병합` 로 보인다. `QStandardPaths` 값을 `os.path.normpath` 없이 이어 붙인 탓.
4. **잘리거나 한 글자로 줄어든 단추·칸(중).** 환경 설정 일반의 폴더 고르기 단추가 `setFixedWidth(32)` 로 「…」 대신 「.」만 보이고, 단축키 표의 키 칸이 좁아 `Ctrl+Shift+Tab` 앞이 잘린다(함정 11-08 과 같은 뿌리).
5. **같은 것을 두 이름으로 부른다(중).** 「쪽」과 「페이지」(오른쪽 클릭 「페이지 가로 가운데」와 맞춤 창 「쪽 가로 가운데」), 「사용자 지정」과 「사용자 정의」(인쇄만), 「입력」과 「넣으십시오」, 상태줄 「~고르세요」(해요체)와 대화상자 「~하십시오」가 섞인다.
