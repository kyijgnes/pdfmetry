# PDF메트리 이어서 (갱신 2026-11-05, 라운드 16 끝 0.2.20, 다음 라운드 17)

목표 한 줄: 알PDF 의 쓰는 기능을 디테일까지 따라가는 윈도우 PDF 편집기(파이썬·PySide6·PyMuPDF).
지금 자리: 설치본 0.2.20(GitHub 공개 저장소 `kyijgnes/rpdf` 릴리스). 시험 744개 통과·3개 건너뜀(전체 54분). 알PDF 기능명세 여섯 권 대조를 다 마치고 구현까지 끝냄.
라운드 1~15(11-01~11-04): 구성·편집·꾸미기·주석·파일·보기·화면틀·검색·설정·변환·도구 권을 명세대로(라운드마다 한 줄 기록은 `git log docs/이어서.md` 의 11-04 판).

라운드 16(11-05): 양식·보안 권 대조 `참고\설계\대조_양식보안.md`(git 밖, 결정 15) 뒤 가~라 구현. 양식 칸 만들기·여러 칸 고르기·복제·Tab 차례(`form_tools.py`), 필드 속성 창·서식·계산(`dlg_field_props.py`·`engine/form_props.py`·`form_calc.py`), 암호 창·소유자 암호·보호 띠와 쓰기 막기(`dlg_security.py`), 교정 패널·숨은 데이터(`dlg_redact.py`·`redact_panel.py`), 디지털 서명 pyHanko(`engine/dsign.py`·`dlg_dsign.py`·`sign_bar.py`: 디지털 ID 만들기 RSA 2048·5년, 서명·검증·모든 서명 제거, 서명 칸 우클릭, 서명된 문서 띠). 보호 문서에선 「모든 서명 제거」도 막음.

## 확정 결정 (되묻지 않는다)
- 10-20 알PDF 코드·자원은 옮기지 않는다. 분석 명세를 보고 직접 짠다(`설계.md` 0절).
- 10-21 분석 자료는 공개 저장소에 두지 않는다. 저장소 밖 `참고\알PDF분석\`(git 무시)에만, 명세 내용을 커밋 메시지·주석·문서에 옮겨 적지 않는다.
- 10-21 개인 무료 비영리 배포, AGPL-3.0. 이스트소프트와 무관 문구 유지.
- 10-29 이름 PDF메트리(영문 PDFmetry). 저장소 주소·서명 머리·`/RPDFDeco` 같은 옛 열쇠는 바꾸지 않는다.
- 11-01 꾸미기: 글꼴 칸은 윈도우 글꼴 전부(한글 없으면 맑은 고딕으로 대신), 베이츠는 알PDF 대로(기본은 범위 밖 쪽도 셈, 「번호만 증가」면 넣은 쪽끼리), 「쪽 번호」 단추는 「더보기」 안 「페이지 번호」로 옮김.
- 11-01 편집 탭: 텍스트 모드(선·단락)와 처음 쓸 때 안내 풍선은 만들지 않음. 글자 서식은 굵게·기울임·크기·색·정렬까지(insert_htmlbox 전환은 나중에 따로).
- 11-02 주석(대조_주석.md 결정 일곱, 권장안대로): ① 새로 찍는 스탬프만 진짜 Stamp 주석(옛 것은 읽기 호환) ② 서명도 Stamp 주석, 그리기·타이핑·사진 입력 창 ③ 메모 생성은 안 만듦 ④ 글 주석 글꼴은 맑은 고딕 그대로(insert_htmlbox 전환 때 같이) ⑤ 작성자 빈 값이면 Windows 사용자 이름 ⑥ 측정 스냅은 끝점·중점만 먼저 ⑦ 켜진 도구를 다시 누르면 빠른 스타일(끄기는 Esc·손 도구).
- 11-03 파일·보기(대조_파일보기.md 결정 13, 권장안대로): 환경 설정은 왼쪽 단추 일곱 페이지(일반·글꼴·OCR·단위·비밀번호·빈 PDF·단축키), 자동 저장은 원본이 아니라 `%APPDATA%\PDFmetry\복구\` 사본, 사전 비밀번호는 DPAPI 로 덮어 저장, 속성 창 프로그램·생성기는 읽기 전용(우리만의 암호·양식·글자층 줄은 남김), 흑백 인쇄 기본 끔 유지, 파일에서 생성은 결과를 저장 안 된 새 탭으로, 스캐너·포트폴리오·OFD·URL 생성은 안 만듦, 내보내기 전 저장 묻기 없음, 내보내기는 jpeg·bmp·gif·tiff·xml 더함(옛 오피스·hwp 안 함), 확대는 알PDF 단계표로 5~1600%, 전체 화면은 앱 창에서 막대 다 숨김·Esc, 배경 다섯 모드는 쪽 그림에 색 곱하기, 보기 회전을 화면만으로 바꾸는 것은 나중 단독 덩어리(그 전엔 메뉴 문구만).
- 11-03 화면틀·검색·설정(대조_화면틀.md 결정 12, 권장안대로): 스킨은 시스템·라이트·다크(클래식 안 함), 왼쪽 막대 통째 접기·기억, Ctrl+T 는 문서 위 떠 있는 검색 판(패널 바꾸기 칸 유지), 북마크로 목차 쪽 만들기, 첨부는 PDF 면 새 탭·그 밖은 묻고 실행 파일은 막음, 고급 검색은 알PDF 대로·바꾼 결과는 「_바꾸기.pdf」 새 파일로만, 레이어는 이름·삭제·속성·처음 상태까지(재정의 안 함), 상태줄 펼침 단추 둘·접기·아래로 대면 나오기, 빠른 실행 ▾ 위에 체크 여섯, 복사·붙여넣기·쌓는 순서·맞춤·분배는 다음으로 미룸, 일반 설정 남은 알PDF 칸은 안 만듦.
- 11-04 변환·도구(대조_변환도구.md 결정 17, 권장안대로): OCR 은 보이지 않는 글자층만·결과는 「이름_OCR」 새 탭·언어 여러 개 체크(`ocr_langs`)·영역 OCR 은 그 쪽 글자층으로(복사 창 없앰)·스캔본 안내 막대, 변환 일곱 형식에 OCR 칸, Word 표·Excel 한 시트·이미지 테두리·EPUB 표지·「이미지 기반 PDF로」(PPT 글 상자는 나중), PDF/A 는 2b 하나, 변환 저장 위치 기억·결과는 단추로만 열기, 「설정 변환」 모음 창, 압축·병합 전용 창(알PDF 대로, 해상도 목록 버그는 따르지 않음), 비교 결과는 나란히 담은 새 PDF 탭·변경 목록 패널, 평면화는 묻지 않고 「_평면화」 새 탭, 표 인식은 [표 복사](엑셀 저장도 남김), 데이터 추출은 양식 필드 CSV 만, 일괄 편집은 작업 열한 개 창.
- 11-04 기본 레이아웃 「자동」이면 문서의 /SinglePage·두 쪽 보기는 연속 보기로 연다(한글 PDF 가 쪽마다 끊겨 넘어가던 것, `window.py` 탭 열기). 사용자가 직접 고른 한 쪽 보기는 따른다.
- 11-03 보기 회전으로 돌린 화면에서 만든 글상자·글자는 그 화면에서 바로 읽히게(글 방향 = 쪽 회전 + 보기 회전, `annots.free_text`·`add_text` 의 `rotate`).
- 11-05 양식·보안(대조_양식보안.md 결정 15, 권장안대로): 디지털 서명은 pyHanko 로 만든다(결정 9), 디지털 ID 는 `digital_ids` 설정에 인증서 base64 로, 빈 서명 칸 하나면 바로 서명 창, 「암호 풀기」는 리본에서 빼고 보안 창으로, 복제 개수는 격자 칸 수(자기 포함).
- 11-01 쪽 다루는 대화상자는 알PDF 명세의 칸·기본값·문구·동작을 따른다. RPDF 에만 있는 편의는 알PDF 와 부딪치지 않을 때만 남긴다.
