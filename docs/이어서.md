## 함정 (한 번 당한 것)
- 11-09 덩어리 세션이 커밋 전에 멈출 수 있다(테마 세션). 워크트리 `git status` 로 미커밋을 보고 같은 세션에 이어 하라고 보낸다.
- 11-09 offscreen 으로 찍을 때 `QT_QPA_FONTDIR=C:\Windows\Fonts` 를 주지 않으면 글자·아이콘이 전부 네모로 나온다.
- 11-09 Qt 는 대화상자의 첫 QPushButton 을 autoDefault 로 잡아 `QPushButton:default` 빨강이 엉뚱한 단추(찾아보기·삭제)에 칠해지고 Enter 도 그리 간다. 확인 단추에 setDefault, 나머지 autoDefault False.
- 11-08 칸 폭은 `setFixedWidth(숫자)` 로 주지 않는다. `fitwidth.fit(칸, 글자들, floor=…)` 로 글꼴·배율에 맞춘다(쪽 번호 칸이 64px 에 잘림).
- 10-21 공개 전환 때 git 기록을 새로 써서 그 전 가지는 main 과 공통 조상이 없다. `git branch --no-merged` 에 다 뜨므로 끝 커밋 제목이 main 에 있는지로 판단.
- 분석 자료 `참고\알PDF분석\` 는 git 밖이라 워크트리에 없다. 브리프에 전체 경로 `C:\Users\kyijgnes\Desktop\코딩\14. 도구\PDF 앱\참고\알PDF분석\` 를 적고 읽기만. 명세의 줄 번호는 10-20 기준이라 함수 이름으로 찾는다.
- **조정 세션은 사이드바 맨 위에 둔다**(11-01 사용자). 다른 세션 밑에 조정 세션을 띄우지 않는다.
- 자동 알림으로 시작된 턴에서는 `start_session` 이 카드(own_initiative)로만 된다. `cwd` 를 주면 거부되니 빼고, 브리프 첫 걸음에 `git worktree add -b claude/<이름> .claude/worktrees/<이름> main` 을 꼭 적는다(앱이 이 저장소에 워크트리를 못 만든다).
- Fable 설계 세션은 Opus 로 뜬다. 띄운 뒤 `set_session_model(claude-fable-5-1)` 로 바꾸고 브리프를 다시 보낸다(라운드 17).
- `app/ui/dialogs.py`·`window.py` 는 덩어리마다 손대기 쉬운 큰 파일이다. 새 창은 덩어리별 새 파일에, `window.py` 는 분기 몇 줄만. import 줄만 겹치면 둘 다 남긴다.
- 클로드 세션 안에서 HKCU 레지스트리는 MSIX 사본이 보인다. 설치 결과는 `explorer.exe <bat>` 로 띄운 cmd 에서 본다.
- 시험·화면 점검은 `APPDATA` 를 임시 폴더로 돌린다(실제 최근 파일 목록을 건드린 일). 화면 점검은 `python -m app.tests.smoke_ui`, 끝에 `smoke ok` 가 찍혔는지 꼭 본다.

- 두 덩어리가 같은 자료를 저장·읽기로 나누면 이음새가 빈다(라운드 9 측정 선 축척, 11 격자 단위, 17 `_one_step` batch 길 되돌림·글 객체 다시 감싸기). 합칠 때 서로 보고한 빈틈을 시험으로 확인한다.
- 「열린 파일은 그 창으로」 뒤로는 시험에서 같은 파일을 두 창에 못 연다. 사본을 연다.
- 전체 시험 중 PyMuPDF `realloc failed` 로 한 파일이 실패할 때가 있다(동시 시험, 11-09 는 PC 커밋 메모리가 1.4GB 까지 줄었을 때). 그 파일만 다시 돌려 통과하면 넘어간다.
- offscreen Qt 는 HTML 든 클립보드를 남기면 죽는다(11-04). 클립보드에 `setMimeData` 하는 시험은 끝에 `QApplication.clipboard().clear()`. 종료 코드 127·139 가 남는 일이 있어 **통과 줄로 판단**한다.
- 시험이 만든 창은 `close()` 로는 안 지워진다. `app/tests/conftest.py` 의 `sweep()` 이 시험마다 지운다. 새 시험이 전역 창 목록을 만들면 sweep 에 비우기를 더한다(라운드 19, 이것을 빼면 전체 시험이 1시간 30분 돌다 98% 에서 죽었다).
- 11-10 자동 모드는 `release.py`(공개 릴리스)를 막는다. 사용자 승인 뒤 저장소 폴더를 cwd 로 단독 명령으로 돌린다.
- 원격이 공개 GitHub 이다. 푸시 전에 사용자에게 커밋 목록을 보여 주고, diff 에 분석 자료 흔적이 없는지 본다.

- 11-08 Microsoft Print To PDF 드라이버에는 우리 포트 모니터 DLL 을 붙일 수 없다(인쇄 서비스 242 「추가 포트 모니터와 함께 사용할 수 없습니다」). 그래서 로컬 파이프 포트 + 수신기. gcc·ld 는 한글 경로를 못 열어 `build_listener` 가 영문 임시 폴더에서 짓는다. 클로드 세션에서 HKCU Run 등록·관리자 설치는 자동 권한에 막힌다(사용자 허락 뒤 관리자 설치만 됨).
