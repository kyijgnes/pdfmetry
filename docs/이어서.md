## 함정 (한 번 당한 것)
- 10-21 공개 전환 때 git 기록을 새로 써서 그 전 가지는 main 과 공통 조상이 없다. `git branch --no-merged` 에 다 뜨므로 끝 커밋 제목이 main 에 있는지로 판단(11-01 정리 때 10개 지움).
- 분석 자료 `참고\알PDF분석\` 는 git 밖이라 워크트리에 없다. 브리프에 전체 경로 `C:\Users\kyijgnes\Desktop\코딩\14. 도구\PDF 앱\참고\알PDF분석\` 를 적고 읽기만. 명세의 줄 번호(window.py:855 등)는 10-20 기준이라 지금 코드와 어긋난다(함수 이름으로 찾는다).
- 이 조정 세션이 다른 세션에서 시작되면 하위 세션은 카드(own_initiative)로만 띄워진다. `cwd` 를 주면 거부되니 빼고, 브리프 첫 걸음에 `git worktree add -b claude/<이름> .claude/worktrees/<이름> main` 을 적는다(패드메트리에서 당함).
- `app/ui/dialogs.py`·`window.py` 의 `pages_action` 은 덩어리마다 손대기 쉬운 큰 파일이다. 새 대화상자는 덩어리별 새 파일에 두고 `window.py` 는 분기 몇 줄만 고치게 해서 충돌을 줄인다.
- 클로드 세션 안에서 HKCU 레지스트리는 MSIX 사본이 보인다. 설치 결과는 `explorer.exe <bat>` 로 띄운 cmd 에서 본다(`설계.md` 1절).
- 원격이 공개 GitHub 이다. 합치기 전에 사용자에게 가지 목록을 한 번 보여 준다(코딩\CLAUDE.md 코디네이터 5).
